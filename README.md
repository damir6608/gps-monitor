# Макет — мониторинг GPS-трекеров

Интерактивное Angular SPA: 80 автомобилей, 300 событий, четыре изменяемые панели, локальная имитация движения, Яндекс Карты v3. Сервер бизнес-данных не требуется.

## Запуск

В каталоге `gps-monitor`, с Node.js 24.19.0:

```sh
npm ci
npm start
```

Открыть **http://localhost:4200/**. Production-сборка: `npm run build`, результат: `dist/gps-monitor/browser`. Раздавайте каталог через HTTP(S), а не `file://`.

На текущем компьютере системный Node.js — 18.13.0. Подготовлен `run.ps1`, который выбирает доступный Node.js 24.19.0 из окружения Codex, не меняя системную установку:

```powershell
.\run.ps1 install
.\run.ps1 start
# В другом терминале:
.\run.ps1 build
.\run.ps1 test
```

## Ключ Яндекс Карт

Получите свой ключ **JavaScript API v3** в [кабинете разработчика Яндекс](https://developer.tech.yandex.ru/). Разрешите домен, с которого запускаете приложение: `localhost`, а при публикации — рабочий домен.

Два варианта:

1. На карте нажать **Настройки**, ввести ключ и нажать **Подключить**. Демонстрационная оболочка сохраняет ключ в `localStorage` этого браузера.
2. Записать ключ в `public/config.json`: `{"yandexApiKey":"ВАШ_КЛЮЧ"}`. После изменения production-конфигурации пересобрать приложение либо заменить `config.json` в каталоге сборки. Ключ из localStorage имеет приоритет.

Ключ фронтенд-карты виден браузеру; настройте ограничения домена. Чужие ключи не используются. Если SDK уже загружен с другим ключом, сохраните новый ключ и перезагрузите страницу — глобальный SDK Яндекса допускает одну конфигурацию на документ. Несколько рабочих областей на странице используют один ключ и отдельные экземпляры карты.

Без ключа таблицы, карточки, фильтры и имитация полностью работают; вместо вымышленной карты показано состояние подключения. При ошибке доступны подсказка и повторная попытка. Загрузка ограничена 20 секундами.

## Встраивание без роутинга

Перенесите каталоги `src/app/tracker-workspace` и `src/app/core` в хост-приложение. Пакет `@yandex/ymaps3-clusterer` импортируется лениво после `ymaps3.ready` и включён в сборку; подключать CDN кластера не нужно.

```ts
import { Component, signal } from "@angular/core";
import {
  TrackerWorkspaceComponent,
  Tracker,
  TrackerEvent,
  MapSettings,
} from "./tracker-workspace/public-api";

@Component({
  selector: "app-fleet-screen",
  standalone: true,
  imports: [TrackerWorkspaceComponent],
  template: `
    <section class="fleet-container">
      <app-tracker-workspace
        [trackers]="trackers"
        [events]="events"
        [mapSettings]="mapSettings()"
        (selectedTrackerChange)="selected.set($event)"
        (mapKeyChange)="setMapKey($event)"
      />
    </section>
  `,
  styles: [
    `
      .fleet-container {
        height: 800px;
        min-width: 0;
      }
    `,
  ],
})
export class FleetScreenComponent {
  trackers: Tracker[] = []; // загрузка/локальные данные хост-приложения
  events: TrackerEvent[] = [];
  selected = signal<Tracker | null>(null);
  mapSettings = signal<MapSettings>({
    apiKey: "ВАШ_КЛЮЧ",
    center: [37.6, 55.75],
    zoom: 9,
  });
  setMapKey(apiKey: string) {
    this.mapSettings.update((s) => ({ ...s, apiKey }));
  }
}
```

Подключите тему один раз в глобальном SCSS хоста:

```scss
@use "./app/tracker-workspace/theme" as workspace;
@include workspace.theme;
```

Тема ограничена `.tracker-workspace`, включая DOM-маркеры vanilla SDK. Собственная тема Material хоста остаётся самостоятельной. `src/styles.scss` содержит только подключение темы и сброс отступа **демонстрационного** `body:has(> app-root)`; копировать этот сброс в хост не требуется. Размеры `100dvh` принадлежат только демонстрационной оболочке. Компонент занимает 100% родителя; для flex/grid-родителей задавайте `min-height: 0` и явную доступную высоту.

Зарегистрируйте русскую локаль при bootstrap хост-приложения, как в `src/main.ts`: `registerLocaleData(ru)` и `{provide: LOCALE_ID, useValue: 'ru'}`. Paginator переводится собственным provider компонента.

### Контракт данных

- `trackers`: неизменяемый входной массив `Tracker`, стабильные уникальные ID; `history` — хронологический список `TrackPoint`, последний соответствует текущей позиции.
- `events`: массив `TrackerEvent`; `trackerId` ссылается на трекер. Неизвестные ID не попадают в ленту.
- Время — Unix milliseconds. Координаты **[longitude, latitude]**.
- `mapSettings`: ключ, необязательные центр и начальный масштаб. Меняйте объект настроек при явной перенастройке карты; он не должен создаваться заново в каждом рендере родителя.
- `selectedTrackerChange`: выбранный актуальный объект либо `null`; при обновлении телеметрии выбранного объекта также отдаёт обновлённый объект.
- `mapKeyChange`: запрос сохранения ключа. Решение о хранении принимает оболочка, сам компонент ничего не сохраняет глобально.
- Новые входные массивы обновляют данные без сброса фильтров и камеры. Выбор снимается, если объект исчез или перестал соответствовать общим фильтрам.

## Поведение

`WorkspaceState` предоставляется компонентом, не через `providedIn: 'root'`. Signals разделяют входные данные, общие фильтры, фильтры событий, выбор, страницы и сортировки. Все панели используют один экземпляр этого состояния. Входные объекты копируются; имитация не мутирует данные родителя.

Карта получает весь отфильтрованный набор, независимо от страниц. Выбор маркера/события открывает нужную страницу таблицы. Камера меняется только по явным командам выбора, показа всех объектов, маршрута и масштаба. Автообновление её не перемещает.

Сплиттеры: Pointer Events с захватом указателя, стрелки (2%), Shift+стрелки (10%), Home/End; минимальная ширина панели 320px, минимальная высота 210px. При маленьком контейнере доступна прокрутка всей сетки; таблицы и карточка прокручиваются отдельно. Старт: 45/55, 60/40. Сброс расположения отдельный от сброса демонстрации.

`YandexMapAdapter` инкапсулирует vanilla API. Использует `YMapClusterer` и `clusterByGrid({ gridSize: 64 })`. Пакет 0.0.12 кэширует сущности по ID, поэтому при обновлении данных адаптер отсоединяет и присоединяет тот же кластеризатор, инвалидируя кэш. **YMap не пересоздаётся**, камера остаётся на месте. Встроенный в YMap ResizeObserver обрабатывает сплиттеры. Для совпадающих координат/предельного масштаба открывается список автомобилей.

Маршрут — локальная линия истории, без запросов маршрутизации. Отметка события отдельная, убирается через 30 секунд, при снятии выбора или выборе другого объекта. Текущая позиция автомобиля не заменяется координатами события.

Имитация выключена по умолчанию. Каждые 3 секунды обновляется примерно 1/8 трекеров из числа движущихся, по определённой траектории. История каждого трекера ограничена 60 точками, события — 600. Очистка: interval, временный маркер, карта, обработчики сущностей; при уничтожении последнего потребителя незавершённая загрузка SDK отменяется. SDK после успешной загрузки общий для документа.

### Если v3 отвечает `Invalid api key`

В настройках ключа сервиса «JavaScript API» обязательно заполните **«Ограничение по HTTP Referer»**. Для локальной демонстрации укажите только `localhost`. IP-адрес `127.0.0.1` кабинет не принимает в этом поле; ограничение по IP оставьте пустым. Открывайте приложение по `http://localhost:4200/` и повторно введите ключ: localStorage разных адресов не общий. Даже подходящий тип ключа без этого ограничения не удовлетворяет требованиям v3. Изменения могут применяться до 15 минут. Затем нажмите «Повторить». Успешная загрузка JS API 2.1 не подтверждает доступность v3. См. [требования подключения](https://yandex.ru/maps-api/docs/js-api/common/connection/javascript.html).
